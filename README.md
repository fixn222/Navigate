# Navigate

A keyboard-friendly, two-pane file manager for Omarchy, built with C++ and QML.

Navigate has a collapsible filesystem tree, a detailed file list, and a
right-click menu for opening, renaming, copying a path, opening with the
default application, and moving items to the trash.

Run `bin/build`, then launch `build/navigate [path]`.

| Key | Action |
| --- | --- |
| Enter / double-click | Open a file or folder |
| Backspace | Parent folder |
| Ctrl+N | New folder |
| F2 | Rename |
| Delete | Move selected item to trash |
| Ctrl+R | Refresh |
| ? | Show shortcuts |
| Q | Quit |

Right-click an item to open its context menu.
